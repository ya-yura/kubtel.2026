# Kubtel Hotspot Static Screens

Статичный комплект экранов captive portal без Astro, сборщика и внешних зависимостей.

## Файлы

- `index.html` - выбор способа идентификации.
- `phone.html` - ввод телефона перед звонком.
- `voucher.html` - ввод номера ваучера и кода.
- `call.html` - экран бесплатного звонка для завершения идентификации.
- `connected.html` - финальный экран после подключения.
- `hotspot.css` - автономный слой токенов и стили, согласованные с текущей дизайн-системой проекта.
- `hotspot.js` - язык, валидация, маска телефона, рекламный и служебный слоты.
- `config.js` - настройки слотов и URL редиректа.
- `assets/logo-wordmark.svg` - локальная копия логотипа, чтобы страницы открывались без доступа к основному сайту.

## Реклама и объявления

По умолчанию рекламный модуль и служебное объявление выключены, чтобы базовый экран авторизации был коротким.

Включение через `config.js`:

```js
window.KUBTEL_HOTSPOT = {
  announcement: {
    enabled: true
  },
  ad: {
    enabled: true
  }
};
```

Быстрые URL-флаги для интеграции и тестов:

- `?ad=1` - включить рекламный модуль.
- `?ad=0` - выключить рекламный модуль.
- `?announcement=1` - включить служебное объявление.
- `?announcement=0` - выключить служебное объявление.

Если слот выключен, HTML-узел удаляется, сетка перестраивается и пустое место не остается.

## UX-решения

- Добавлен отдельный экран `connected.html`, потому что после идентификации пользователю нужен явный финальный статус, а не молчаливый редирект или зависание на звонке.
- На экране звонка добавлена кнопка проверки подключения после звонка. Это снижает тревожность: пользователь понимает, что делать после короткого сигнала.
- Ввод телефона получил маску, минимальную проверку 10 цифр и понятное сообщение об ошибке.
- Ваучерные поля приводятся к верхнему регистру и не требуют лишних пробелов.
- ENG/RU переключатель сохраняет телефонные и юридические ссылки, меняя только текст интерфейса.
- Рекламный модуль сделан боковым на широких экранах и поточным на мобильных, чтобы не вытеснять форму авторизации.

## Проверка

Страницы проверены как `file://` в headless Chrome:

- desktop `849x778`;
- mobile `390x844`;
- отсутствие горизонтального overflow;
- переход `phone.html -> call.html` при валидном номере;
- ошибка при коротком номере;
- переключение языка;
- включение и выключение `ad`/`announcement` без пустых зон.
