# KUBTEL UX case — visual pack

Пакет визуализаций собран под тезис кейса: **status first, честная неопределённость, единый case context**.

## Арт-дирекция

- Палитра: `#111317`, `#20242A`, `#C43D87`, `#FFF0F8`, `#4599D8`, `#137A4B`.
- Светлая сцена — для интерфейсных и аналитических артефактов; тёмная — для критических состояний и системных связей.
- Все экраны намеренно оставлены без псевдотекста: вместо случайных букв используются нейтральные текстовые плашки, чтобы поверх можно было положить точный русский UX-copy.
- Визуалы не изображают фактические результаты запуска; метрики показаны как план измерения.

## Рекомендуемая подпись к пакету

> Ретроспективное публичное UX-исследование и продуктовая концепция. Решения не выпускались; визуализации показывают proposed solution и план валидации.

## Принцип использования

Не подписывать визуалы как фактические экраны KUBTEL и не приписывать им измеренный эффект до получения baseline, incident log, payment funnel и подтверждённых данных запуска.
