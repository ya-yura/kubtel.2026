# Compatibility Checklist

## Перед загрузкой на оборудование

- Все ресурсы локальные: нет Google Fonts, CDN, внешних картинок и трекеров.
- Главный HTML называется так, как требует система: `login.html`, `portal.html` или `index.html`.
- Формы отправляют данные в нужный `action`.
- Имена полей совпадают с контрактом контроллера/сервиса.
- Согласие с правилами обязательно и не скрыто.
- Текст agreement утвержден юридически.
- Домен портала, SMS API и внешние ссылки добавлены в walled garden, если используются до авторизации.
- JS не является единственным способом отправить форму.
- Ошибки сервера выводятся безопасно и понятно.

## Тесты устройств

- iPhone Safari captive mini-browser.
- Android Chrome captive portal window.
- Windows Chrome/Edge.
- macOS Safari/Chrome.
- Экран 320px шириной.
- Экран 390px шириной.
- Планшет 768px шириной.
- Desktop 1366px и 1440px.

## Сценарии

- Первый вход без cookie/localStorage.
- SMS: короткий телефон показывает ошибку.
- SMS: корректный телефон допускает запрос кода.
- SMS: повторная отправка блокируется таймером.
- Код: пустой код показывает ошибку.
- Ваучер: пустой номер или код показывает ошибку.
- Согласие не отмечено: вход блокируется.
- Успех ведет на status/continue URL.
- Ошибка ведет обратно на login.
- Logout возвращает к повторному входу.
- Реклама включена и выключена без пустой колонки.
- RU/ENG не ломает ссылки и layout.

## Тесты сети

- Portal открывается при переходе на `http://neverssl.com`.
- HTTPS-запросы не дают пугающий certificate mismatch, если оборудование это настраивает.
- DNS доступен до авторизации.
- После grant есть доступ в интернет.
- После logout или timeout доступ снова закрыт.
- Повторная авторизация на том же устройстве не ломает состояние.

## Производительность

- Общий размер HTML/CSS/JS/логотипа приемлем для загрузки на роутер.
- Нет блокирующих внешних запросов.
- Нет больших изображений в первом экране.
- Баннеры сжаты и имеют локальные относительные пути.
- Анимации не меняют opacity основного текста.
