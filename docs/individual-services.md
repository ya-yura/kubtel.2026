# Услуги для физических лиц

Каталог физических лиц находится в `src/content/configurator/individual.json`.

## Как добавить поле

Добавьте объект в `services[].fields` нужной услуги. Компонент и серверный расчёт поддерживают:

- `select` и `radio` — один вариант из `choices`;
- `checkbox` — флаг или несколько вариантов через `multiple: true`;
- `counter` — количество с `min`, `max`, `step` и ценой за единицу.

У каждого варианта есть `monthlyPrice` и `oneTimePrice`. Для отдельной услуги можно добавить описание,
подсказку, единицу измерения и значение по умолчанию. Новый объект автоматически появляется в
конфигураторе, расчёте, серверной заявке, email/Telegram/CRM payload и локальном outbox.

Например, аренда роутера и аренда ТВ-приставки — обычные варианты в поле устройства, поэтому для
добавления будущей аренды камеры или другого оборудования не требуется менять UI-компонент.

Каналы, ссылки на магазины приложений и юридические документы находятся в секциях `tv`, `cctv` и
`internet` того же каталога. После изменения контента нужно выполнить `npm run check` и `npm test`.
