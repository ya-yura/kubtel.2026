# Бесплатный CMS-контур Kubtel

## Решение

Основной редакторский вход — Decap CMS по адресу `/admin/`. Он хранит контент в GitHub как обычные JSON-файлы в `src/content/`, поэтому:

- не требует отдельной платной лицензии или базы данных;
- оставляет историю изменений и возможность отката;
- не меняет URL: slug редактируется отдельно и защищён редакторской инструкцией;
- продолжает работать вместе с локальным content layer и fallback-режимом;
- сохраняет Strapi в `cms/strapi/` как необязательный путь для будущей команды и сложных ролей.

## Публикация

1. Откройте `/admin/` на опубликованном сайте.
2. Авторизуйтесь через GitHub и выберите запись.
3. Сохраните запись как draft, отправьте на review и только после проверки опубликуйте.
4. GitHub сохраняет коммит и позволяет откатить запись без ручного восстановления базы.

Для production нужен OAuth-прокси GitHub/Netlify Identity. Его секреты не должны попадать в `config.yml` или клиентский код. Локальный режим включается через `npx decap-server` и `local_backend: true`.

`/admin/` — рабочий адрес, который перенаправляет на статическую оболочку `/admin/index.html`; конфигурация при этом остаётся `/admin/config.yml`. Запуск `public/admin/index.html` двойным кликом через `file://` не является поддерживаемым способом и приводит к ошибке `Failed to fetch config.yml` из-за ограничений браузера.

## Правила сохранения SEO

- существующие страницы остаются в `src/pages/`;
- `trailingSlash: "always"` сохраняет текущий формат адресов;
- canonical, sitemap и robots остаются в Astro;
- legacy B2B-адреса проходят через 301-redirect в `src/lib/redirects/business-legacy.ts`;
- slug опубликованного контента нельзя менять без отдельной redirect-задачи;
- при проблеме CMS сайт обслуживает локальный контент через `CMS_FALLBACK_TO_LOCAL=true`.

## Контентный контракт

Редактор меняет текст и коммерческие поля, но не токены, формулы калькуляторов, маршруты или HTML. Проверочные статусы `confirmed`, `needs_verification` и `draft` сохраняют защиту от публикации неподтверждённых цен, сроков и обещаний.
