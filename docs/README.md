## Важное ограничение по секретам

В документации намеренно нет реальных логинов, паролей, токенов и приватных ключей. Их передают только через одобренный менеджер секретов или корпоративный канал ИТ. В Git и в переписке с Codex должны находиться только названия переменных, инструкции и обезличенные placeholders.

Инфраструктурные шаблоны находятся в [`ops/`](../ops/) и корне проекта: Dockerfile, Compose, Nginx-конфигурация и release-скрипты. Автоматизированный production-запуск подготовлен в [`.github/workflows/production.yml`](../.github/workflows/production.yml) и включается только после настройки защищённого GitHub Environment `production` и секретов из задания ИТ.
