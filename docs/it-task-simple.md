# Короткая задача для программистов

Нужно развернуть обновлённый сайт Kubtel из [репозитория проекта](https://github.com/ya-yura/kubtel.2026) на боевом сервере. Адрес сайта должен остаться прежним: [https://kubtel.ru](https://kubtel.ru). Важно сохранить существующие адреса страниц и настроить перенаправления так, чтобы не пострадали SEO и поисковая выдача. Сайт должен нормально открываться на компьютере и телефоне, работать с формами заявок, страницами оплаты, разделом для бизнеса и редактором сайта по адресу `/admin/`.

Все необходимые файлы для установки уже находятся в репозитории: [Dockerfile](../Dockerfile), [compose.production.yml](../compose.production.yml), [Nginx-конфигурация](../ops/nginx-kubtel.conf) и [инструкция по развёртыванию](./production-deployment-maintenance.md). Прошу установить сайт, подключить домен и HTTPS, настроить необходимые переменные для заявок и CMS, проверить основные страницы, формы и старые адреса, а затем сообщить мне рабочую ссылку, способ входа в редактор и контакт ответственного за дальнейшие обновления. В дальнейшем сайт должен обновляться из этого репозитория по согласованным изменениям, без ручного редактирования файлов на сервере.
